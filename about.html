Hero Mission: The Healthy Choice

Play the game · Source repository

What it is

Hero Mission: The Healthy Choice is a randomized 10-question health-and-safety quiz game developed as part of a multi-game interactive children’s edutainment activation in the UAE.

Game rule

Each run samples 10 questions from a built-in bank of 17. Every question presents two choices. Correct choices add one point; incorrect choices store that question’s associated advice for the final report.

question → two choices → score update → next question → score out of 10 → final report

Topics

The current bank includes vaping and nicotine, unknown pills, drug offers, peer pressure, trusted adults, stress, lungs and heart health, exercise, smoking effects, and personal body control.

Activation context

This game belongs to the same kids-* game set developed for the multi-game interactive children’s edutainment activation in the UAE.

Evidence boundary

The game implements a quiz score and feedback mechanism. The repository does not contain a validation study establishing that score as a clinical, educational, behavioral, or health assessment, or evidence of learning transfer outside the game.
