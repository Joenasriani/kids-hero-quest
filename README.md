# Hero Mission: The Healthy Choice

Play: https://joenasriani.github.io/kids-hero-quest/

Hero Mission: The Healthy Choice is a randomized 10-question health-and-safety quiz game.

## How it plays

Each run selects 10 questions from a built-in bank of 17 two-choice prompts.

A correct response adds one point. An incorrect response stores the question's advice text for the final report.

**random question → two choices → score update → repeat 10 times → final report**

The end screen shows the score out of 10 and combines the score band with advice from the first missed question when applicable.

## Topics

The current bank includes vaping and nicotine, unknown pills, drug offers, peer pressure, trusted adults, stress, lungs and heart health, exercise, smoking effects and personal control over one's body.

## Content note

The quiz is simplified health-and-safety game content, not a clinical, educational or behavioral assessment.
